# ATM Management System

## 📌 Project Overview

The ATM Management System is a simple Python-based project that simulates the basic operations of an Automated Teller Machine (ATM).

This project allows users to securely access their account using a PIN and perform common banking operations such as checking balance, depositing money, withdrawing money, and exiting the system.

## 🛠️ Technologies Used

- Python
- Python Functions
- Conditional Statements
- Loops
- Variables
- User Input

## ✨ Features

- PIN-based login
- Check account balance
- Deposit money
- Withdraw money
- Balance validation
- Insufficient balance checking
- User-friendly menu
- Exit option

## 🔄 How the System Works

1. The user enters their PIN.
2. The system verifies the PIN.
3. If the PIN is correct, the ATM menu is displayed.
4. The user selects an operation.
5. The system performs the selected operation.
6. The updated balance is displayed.
7. The user can continue performing transactions or exit.

## 💻 Operations

### 1. Check Balance
Displays the current account balance.

### 2. Deposit Money
Allows the user to enter an amount and add it to their account balance.

### 3. Withdraw Money
Allows the user to withdraw money if sufficient balance is available.

### 4. Exit
Closes the ATM system.
